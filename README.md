# 🚀 YouTube Downloader Telegram Bot (YTDLTG)

Асинхронный Telegram-бот на базе `aiogram 3` и `yt-dlp` для удобного скачивания видео и аудио с YouTube прямо в мессенджер.

## ✨ Основные возможности

- **Скачивание видео:** Поддержка форматов 1080p, 720p и 480p (в формате MP4).
- **Скачивание аудио:** Извлечение звука в формате MP3 (192 kbps).
- **Асинхронность:** Бот не блокируется при скачивании тяжелых файлов благодаря выносу задач в отдельные потоки.
- **Умная склейка:** Автоматическое объединение видео и аудио потоков высокого качества с помощью FFmpeg.
- **Обход блокировок:** Использование маскировки под мобильные клиенты (Android/iOS) для обхода базовых защит YouTube.

## 🛠 Требования к системе

Для корректной работы бота на сервере или локальном компьютере должны быть установлены:
1. **Python 3.8+**
2. **FFmpeg** (обязательно для склейки видео со звуком и конвертации в MP3).
3. **Node.js** (для решения внутренних JavaScript-проверок YouTube).

## 📁 Структура проекта

- `main.py` — Точка входа, запуск бота и диспетчера.
- `config.py` — Конфигурационные данные (токен, константы).
- `handlers.py` — Обработчики сообщений и нажатий на кнопки (Inline).
- `keyboards.py` — Клавиатуры и пользовательские интерфейсы.
- `downloader.py` — Изолированная логика скачивания и взаимодействия с `yt-dlp`.

## ⚠️ Возможные проблемы и их решения

YouTube часто меняет алгоритмы защиты. Если бот начал выдавать ошибку `Sign in to confirm you're not a bot`, выполните следующие шаги:

1. **Обновите yt-dlp** (это нужно делать регулярно):
   ```bash
   pip install --upgrade yt-dlp
   
Используйте cookies:
Если обновление не помогло, экспортируйте файлы cookie из вашего браузера (например, через расширение Get cookies.txt LOCALLY) в файл cookies.txt, положите его в корень проекта и раскомментируйте соответствующую строку в файле downloader.py.

📝 Лимит Telegram API
Стандартный API Telegram позволяет ботам отправлять файлы размером не более 50 МБ. Если скачанный файл превышает этот лимит, бот уведомит об этом пользователя и удалит файл с сервера. Для отправки файлов до 2 ГБ потребуется развертывание локального сервера Telegram Bot API.
